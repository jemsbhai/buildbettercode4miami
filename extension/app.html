1 Connect on this computer

The deterministic tools run on your computer without a model key, subscription, or owner-funded server. The local companion must remain open.

First-time setup
  1. Copy this extension ID: Loading…
  2. In the source folder, start npm run sheets:local -- --extension-id=YOUR_EXTENSION_ID. For fictional fixtures, add --demo.
  3. Enter the generated connection token below. It stays in this browser session, and is cleared when the extension reloads or the browser restarts.

Google authorization requires your own configured OAuth client. No Google token or OpenAI key is included in this package.

2 Choose the scope

Discovery reads spreadsheet names and IDs. A scan reads only the workbooks you select, including their eligible tabs. Known private counseling tabs and columns are excluded; labels cannot identify every sensitive cell.

3 Understand and review

Required before correction: confirm column mappings

Review inferred mappings, required fields, amount units and dates. Adjust them as needed, then confirm and rescan. Column numbers refer to the original tab. Ambiguous dates require an explicit interpretation.

Findings

Duplicate gifts and conflicting identities require a person’s decision. Tidepath keeps every gift row and its cents. Proposed identity corrections include every matching donor row in this scope; selecting one selects the full group for your review.

4 Approve the exact correction copies

Only the checked changes below will be applied to new data workbooks. The source workbooks remain intact. Copies exclude private tabs/columns and do not reproduce formatting, charts, sharing or other workbook features. Formula-bearing source tabs cannot be copied by this version.

The companion rechecks source versions before copying and verifies new values. If a source changed, rescan and review again.

Any API use is billed to your OpenAI account. This is not free inference. Calls and tokens are bounded, but these limits do not guarantee an exact bill. Advice does not approve or apply changes.
